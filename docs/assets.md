## Fonts and UI

- Golos Text: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/golostext).
- Literata: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/literata).
- Both SIL Open Font License; license files are delivered beside the self-hosted
  Cyrillic/Latin WOFF2 subsets in `apps/web/public/fonts/`. Fetch via the Google
  Fonts Git mirror on jsDelivr; `scripts/fetch-fonts.mjs`, `prepare-fonts.py`.
  Literata retains weights 400–700 with optical size fixed at 48 for a smaller
  display font download (93,912 bytes). Golos retains its weight axis (65,036 bytes).
- UI icons: official `@radix-ui/react-icons`, MIT package license.
- Wordmark and favicon: original text treatment, no copied brand symbol.
- Product initial labels and weekly roast note: original HTML/CSS typography.

Asset hashes and delivery sizes are recorded in the final verification evidence.
